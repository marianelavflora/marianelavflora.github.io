# Projects folder

Drop your real photos here (hackathons, gamejams, facu projects) and swap
them into the `.card-media` blocks in `index.html`'s Projects & Achievements
section — replace the placeholder `<div class="card-media placeholder-media">...`
with:

```html
<div class="card-media">
  <img src="projects/your-photo.jpg" alt="Describe the photo" />
</div>
```

Also update each card's title, tag, description and date to the real story.
